# Monexus Finance

> Plataforma moderna de gestão financeira pessoal desenvolvida com Java e Spring Boot.

## Status

🚧 Em desenvolvimento

## Documentação

Toda a documentação do projeto encontra-se na pasta `docs/`.

## Tecnologias previstas

- Java 25
- Spring Boot
- Spring Security
- JWT
- Spring Data JPA
- Hibernate
- MySQL
- Docker
- GitHub Actions
- OpenAPI / Swagger
- React
- Tailwind CSS

## Objetivo

Construir uma plataforma moderna de organização financeira pessoal focada em clareza, simplicidade e evolução financeira do usuário.
