# Frontend Design System

## Objetivo

Este documento define a identidade visual oficial do Monexus Finance.

Todo componente visual deverá seguir estas diretrizes.

---

# Conceito

O Monexus Finance transmite:

- organização;
- prosperidade;
- clareza;
- tranquilidade;
- controle.

A interface deve reduzir a ansiedade financeira do usuário.

---

# Estilo Visual

O sistema seguirá o conceito:

**Clean UI + Subtle Depth**

Inspirado em:

- Stripe
- Linear
- Notion

# Dashboard

Ao abrir o Dashboard o usuário deverá visualizar imediatamente:

- saldo atual;
- receitas do mês;
- despesas do mês;
- saldo do mês.

Estas informações devem ocupar a primeira área visível da tela.

---

# Gráficos

Os gráficos utilizarão:

- linhas suaves;
- preenchimento translúcido;
- poucas cores;
- foco na leitura.

# Tema

Tema padrão

```
Light
```

Tema alternativo

```
Dark
```

Toda a aplicação deverá utilizar tokens semânticos.

Nunca utilizar cores diretamente nos componentes.

# Acessibilidade

Seguir WCAG.

Evitar:

- preto absoluto;
- vermelho agressivo;
- contraste inadequado.

---

# Filosofia

Toda decisão visual deverá responder:

Esta interface está:

- simples?
- elegante?
- intuitiva?
- rápida?
- agradável?

Se qualquer resposta for "não", o componente deverá ser revisado.
