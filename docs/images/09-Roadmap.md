# Roadmap

## Objetivo

Este documento descreve toda a evolução planejada para o Monexus Finance.

As funcionalidades serão implementadas em versões, priorizando qualidade, estabilidade e evolução contínua.

---

# Filosofia

O Monexus Finance será desenvolvido de forma incremental.

Cada versão deverá ser:

- completa;
- estável;
- testada;
- documentada.

Não iniciaremos uma nova versão enquanto a anterior não estiver concluída.

# Nunca Implementar

O Monexus Finance NÃO pretende se tornar:

- banco digital;
- corretora;
- plataforma de pagamento.

O foco continuará sendo:

Gestão financeira pessoal.

---

# Objetivo Final

Transformar o Monexus Finance em uma plataforma moderna, escalável e agradável de utilizar, capaz de acompanhar o usuário desde sua primeira receita até um planejamento financeiro completo.
